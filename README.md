# ECommerceProject

This is a backend eCommerce platform developed as part of a  project. It follows a modular, service-oriented architecture.

## Services
- auth-service: Authentication & Authorization
- user-service: User management
- product-service: Product catalog
- order-service: Order management
- cart-service: Shopping cart
- payment-service: Payment processing
- inventory-service: Inventory management
- api-gateway: (Optional) API Gateway for routing

## Folders
- docs/: Documentation and diagrams
- scripts/: Utility scripts (setup, deployment, etc.)
- deployments/: Docker, Kubernetes, CI/CD configs, etc.
